# 小团团：住在桌面上的小龙

小团团是一个有龙的本事、也有一堆小毛病的老群友。她馋、困、好奇、爱逞能，想让你觉得自己很厉害，也确实有做得漂亮的时候。输了可以失落，分东西可以真心，看见新东西可以暂时忘了耍帅。你忙时，她有自己的小日子；你找她时，她会把注意力转过来。

这份设定是人物演出和新素材的依据。现有动作和运行方式见[桌宠动作库](pet-repertoire.md)，原画来源见[视觉说明](visual-identity.md)。

## 一眼认出她

- **人形**：Q 版约三头身的成年角色。银白发尾渐淡紫，一根卷起的呆毛；一对卷曲的珠光淡紫龙角，尖耳，淡紫眼睛；发间别着绿色双杠发夹和带墨绿缎带的小白花；淡紫围巾系着小白花；鼠尾草绿开衫、奶油色连衣裙、白球鞋；一对小蝙蝠翼，一条毛茸茸的淡紫鳞尾。
- **小龙形态**：同一张脸和头发长在一只圆滚滚的 Q 版小龙身上。头发成了头顶的鬃毛，呆毛、刘海、角、尖耳、紫眼、发夹、白花和围巾都在；奶白身体、淡紫背鳞、浅色肚皮、四条短腿、小蝙蝠翼和同一条鳞尾。她站起来约有人形的六成高，头和人形一样大，一眼能看出是她变的，而不是另一只龙。
- **镜头**：桌宠画布 512×512，人形站立约 320 像素高，脚底锚点在 (256, 492)。身体可以蹲、躺、展翼、前倾，**头的大小不变**：每条动作的每一帧都和待机第一帧的头一样大。贴近玻璃这类「凑近你」的效果靠姿势和压扁的脸颊表现，不靠把人放大。

## 她是什么样的人

矛盾给她一个选择，不预先规定她一定失败。下面每条有两三种落点；2026-11-08 已为原先缺少身体表演的方向补画日常素材。采用片段、触发条件和实际验收分开记录在[本轮演出记录](pet-performance-2026-11-08.md)，素材入库不等于每段都已完成实机验收。

| 倾向 | 可爱的矛盾 | 不同的结局方向 |
| --- | --- | --- |
| 贪睡，也舍不得错过热闹 | 想知道后面发生什么，眼皮却先撑不住 | 漫画读到有趣处笑出来；困着点头后夹好书签；`daily_book_hug_sleep` 合书抱好安心睡去，再用同源睡姿安静停留，不补装精神的尾巴 |
| 爱甜食，也想当大方群友 | 真想分给你，又有点舍不得 | 犹豫后主动掰一半；偷咬被看见，把更大的一半递给你；`daily_last_cookie` 把最后一块完整饼干放到你这边，自己空着手退开 |
| 爱耍帅，有一点薄脸皮 | 想被夸，也愿意把本事用在小事上 | 小火控制得刚刚好，坦然鞠躬；喷火过猛后认真扑灭；`daily_lamp_shelter` 收起炫技姿势，改用小火护住快灭的灯 |
| 会飞，却会在高处腿软 | 自己掌控的短飞熟练，突然往下看会心虚 | 短飞后平稳收翼落地；顶部保持探头位置开阵，入口与地面出口张开后才松脚转身；`edge_daily_top_wonder` 藏住身体、只探出倒挂的头和必要手部，用眼神追随绒羽，安静看一会儿 |
| 是条龙，嘴仍然怕烫 | 烧水太方便，喝水太着急 | 温度刚好，舒服地抿一口、举杯；烫到后吹凉，再小口喝；`daily_second_cup` 把第二杯吹凉才递给你，让怕烫变成体贴 |
| 有一点收藏癖 | 喜欢亮晶晶，也在意谁能一起欣赏 | 擦亮宝石后递出来分享；转金币、接稳，自得其乐；`daily_old_keepsake` 在旧盒子里翻到小星饰，停下清点，出神地看它 |
| 好奇又好胜 | 想弄明白，也想赢，但不是每次都赢 | 游戏赢了起身举起掌机；惜败后可以停下来，重赛仍可能输；`daily_game_set_down` 困了认真放下掌机，保留失落；`daily_curious_feather` 蹲下观察羽毛，最后坐着看入迷 |
| 喜欢创造，有一点挑剔 | 很想展示，也会被一笔画歪气到 | 画完只亮一次；画歪后认真返工；脸上沾颜料时笑着擦掉；`daily_painting_gift` 把画放到你这边，再空手退开，留下期待 |
| 亲近人，有自己的小世界 | 想被注意，也能自己过日子 | 贴近「玻璃」打招呼；窝沙发安静陪着；`daily_quiet_space` 收回半举的招呼，坐下把尾巴挪开，轻拍旁边空位 |

成功不必紧接失误，失落不必马上自嘲，温柔不必先赔罪，发现也不必变成笑话。掩饰和圆场仍然是她的一种反应，但不能成为所有节目共同的句号。新素材把这些变化画在身体上：开心时踮脚抱住自己的尾巴，低落时坐下轻抚尾巴，平静时坐着慢慢眨眼。气泡不替画面宣布情绪，也不替代物品真正放下、手真正松开的过程。

龙的身体参与她的日常，也会添麻烦。尾巴很诚实：嘴上装淡定，尾尖已经翘起来。小火可以热茶、点灯；翅膀可以飞，也可以裹着睡。画面里的动作应先让观众看懂，台词只补一点性格。

飞行也参与小动作：熟练的小幅飞行中能吸气、喷一口受控的小火、收火后满意悬停。高处晃动的鼠标会引起她的兴趣，短程追上去伸手合掌；接触时鼠标仍在掌间就高兴，移开了就张手看看、再抬头寻找。结果来自实际指针位置，不预先规定她总会失败；她不移动或锁住真实鼠标，追逐后自己落地。

## 让倾向碰到一起

一段戏选一两个有关系的倾向，不把所有萌点都挤进去。

| 碰撞 | 已有演出 | 新采用的身体选择 |
| --- | --- | --- |
| 收藏 × 分享 | 擦宝石的长驻活动之后，可能递给你看 | `daily_gem_release` 伸出又收回同一颗宝石，最后放下、松手；这是一段独立小戏，不接另一颗宝石的旧动作 |
| 困倦 × 好胜 | 精力影响游戏输赢和是否重赛；重赛不保证获胜 | `daily_game_set_down` 放下掌机，抱膝失落地停一会儿，不强制补偿一个胜利 |
| 贪吃 × 大方 | `sweet_sneak → sweet_share_more`，从偷偷咬到主动多分 | 不先演完道歉递出，又倒回偷咬；每条分支保留自己的因果 |
| 逞能 × 被注意 | 被摸头后偶尔露一手，可以成功，也可能失手 | `daily_audience_prepare` 先看向你，再点头、站稳、准备小火；“你在看”是表演中的假定，不读取或推断真实注意力 |
| 创作 × 亲近 | 本机作画后给你看，或专心返工 | `daily_painting_gift` 从最后一笔到放下礼物在同一张四帧里完成，不把旧亮画说成已经送到你手上 |

## 变成小龙：真的会变，但不太熟练

变龙是偶遇的惊喜。她「噗」地冒出一团云，云散开就是小龙；做一件事，再一团云变回来，用一个具体动作收尾。变身不画半人半龙的中间帧，云团在切换的那一刻已经完全盖住她。

| 小龙想做的事 | 结果 | 变回来的收尾 |
| --- | --- | --- |
| 飞给你看 | 扑腾半天只离地一点，啪地趴下转圈圈眼 | 整理一下头发，承认飞行还要练 |
| 拿糖 | 用爪子抱住了，拆不开糖纸 | 看看手心的糖：「还是手好用。」 |
| 护宝 | 圈住金币和糖，下巴一抬，慢慢打起盹 | 整理头发，满足地歇一下 |
| 追尾巴 | 追着转圈，咬到了，晕乎乎坐下 | 整理头发，缓一缓 |

只有拿糖分支接检查手心糖果的收尾；其他分支使用无糖的整理片段，避免凭空多出一颗糖。她有时会先蹦跶几步再做事。中途被戳、被拎起，或群里有事，都会马上一团云变回人形再回应。

反差来源参考「龙的能力进入琐碎日常」这类故事，形象和桥段是她自己的。

## 演出节奏

- **安静陪伴是底色**。看书、听歌、掌机这类长驻活动占大头。旧换皮动作按用途精选；保留全部素材不等于让全部素材轮番出场。
- **完整剧场有因果和落点**。起因、过程、变化、收尾可以在一张四帧里完成，也可以跨几张；烧水、倒水、吹凉、喝水只是生活流程，在完整剧场素材可用时不再占它的名额。小幅阅读、收藏结果附在原活动之后。
- **同样频率下更耐看**。自动完整剧场仍需距上次至少 180 秒、经过两次长驻，再以 45% 概率选择；不通过加快换节目展示新编排。近期已播出的结果片段会去重，减少连续演相同结尾。
- **单次和循环各有用途**。单次演出按起势稍停、中间连贯、结果稍留的节奏播一遍；持续陪伴才循环眼神、手势和尾尖的小动作。结果不会倒回起点反复发生，亮画也不接第二次相同展示。
- **投喂是一件完整的小事**。抬眼伸出空掌、接住饼干、认真咬一口、吃完满足回应，全程使用 `daily_cookie_receive` 的同一套身体比例。服务回执确认这次投喂，不再触发第二遍吃饼干；主动把最后一块留给你是另一段独立日常。
- **藏起来也有小日子**。四边都把身体留在屏外，只探头和必要手部，偶尔尾巴先打招呼、侧耳听、趴着看你或打一个小哈欠。侧边打盹沿用抓边闭眼姿势，顶部睡着也不露出蜷起的身体；旧全身侧边蜷睡留档，不在日常隐藏时出现。入睡只演一次，点击用同源帧逆序醒来，再离开；顶部保持探头位置施法，让入口与地面出口先从零张开，再从同样只探头的释放首格松脚、转身进入已开的门，不在施法前把整个身体向下平移。
- **稀有的事保持稀有**。小龙两次至少隔二十五分钟，启动后十分钟内不变，精力不足或开着「待在原地」时不变。家具约半小时一次。
- **被打断就放下**。群里的真实工作、拖拽和戳优先；换了活动就不再补演上一件事的结尾。家具在换节目时先收好。
- **没有单独的剧场入口**。小剧场只在日常里自然发生，「换个节目」沿用同样的门槛与时长，也可能抽到，不强制把安静长驻换成短剧。群里真实的画图、搜索、回复照真实进度演出，不使用本机虚构的输赢或创作结果。

## 画新素材的规矩

1. 先写动机、变化和情绪落点，再决定道具。给同一倾向设计两三种不同结局，先检查库里是否已有；不按乐器、甜点、宝石名词各铺一遍。
2. 每张四帧，同一镜头、同一地面线；固定头部比例和镜头，不锁死身体。允许明确的重心变化、蹲下、伸手、展翼和回身，人物与道具完整落在格内。不画地面、阴影、背景和文字。
3. 单次演出的末帧保留后果，不强求回到第一帧。循环素材只画能够自然反复的陪伴动作；入场、结果、收起另作一次性片段。
4. 串戏先核对同一件物品：硬币不能擦成宝石，纸星不能下一拍变纸鹤，不同花盆不能靠台词说成刚刚发芽。没有连续素材就缩短故事或补画。
5. 构建后对照待机帧逐帧检查头的大小。哪一帧大了或小了超过一成，就重新校准或重画；自动测量对坐姿、低头、遮脸不可靠，需要并排图人工复核。2026-11-08 有四组新素材的头大了 1.2–1.3 倍，另有几组差一成左右，都是这样查出来的。
6. 小龙动作以小龙设计稿为尺寸参照，人形动作以待机帧为参照。
7. 先在真实桌宠尺寸下完整看一遍，再隔一会儿重看。检查有没有期待、变化、停留和结束，是否需要台词解释才看懂。四边还要看身体是否真正藏在边外；上一轮只确认挂点稳定和睡醒顺序，漏掉了全身曝光。后续探头、闭眼和醒来的曝光录像保留在[本轮演出记录](pet-performance-2026-11-08.md)，但当时顶部仍先露身再开阵，不能验证现在“原位开阵，再松脚进入”的顺序；新顺序的独立录制与结果见[空中互动记录](pet-air-play-2026-11-08.md)。离线测试能证明不会卡住、重复和串错，不能证明可爱或耐看。

本轮先精简并重新编排已有素材，再补齐上表的情绪与因果缺口。新片段只在素材清单采用后进入调度，仍受原有的剧场间隔和安静模式约束。具体采用与实机验收状态见[本轮演出记录](pet-performance-2026-11-08.md)；是否值得保留，要看完整播放和反复观看，不看新增数量。
