# 小团团：住在桌面上的小龙

小团团是一个有龙的本事、也有一堆小毛病的老群友。她馋、困、好奇、爱逞能，想让你觉得自己很厉害，也确实有做得漂亮的时候。输了可以失落，分东西可以真心，看见新东西可以暂时忘了耍帅。你忙时，她有自己的小日子；你找她时，她会把注意力转过来。

这份设定是人物演出和新素材的依据。现有动作和运行方式见[桌宠动作库](pet-repertoire.md)，原画来源见[视觉说明](visual-identity.md)。

## 一眼认出她

- **人形**：Q 版约三头身的成年角色。银白发尾渐淡紫，一根卷起的呆毛；一对卷曲的珠光淡紫龙角，尖耳，淡紫眼睛；发间别着绿色双杠发夹和带墨绿缎带的小白花；淡紫围巾系着小白花；鼠尾草绿开衫、奶油色连衣裙、白球鞋；一对小蝙蝠翼，一条毛茸茸的淡紫鳞尾。
- **小龙形态**：同一张脸和头发长在一只圆滚滚的 Q 版小龙身上。头发成了头顶的鬃毛，呆毛、刘海、角、尖耳、紫眼、发夹、白花和围巾都在；奶白身体、淡紫背鳞、浅色肚皮、四条短腿、小蝙蝠翼和同一条鳞尾。她站起来约有人形的六成高，头和人形一样大，一眼能看出是她变的，而不是另一只龙。
- **镜头**：桌宠画布 512×512，人形站立约 320 像素高，脚底锚点在 (256, 492)。身体可以蹲、躺、展翼、前倾，**头的大小不变**：每条动作的每一帧都和待机第一帧的头一样大。贴近玻璃这类「凑近你」的效果靠姿势和压扁的脸颊表现，不靠把人放大。

## 她是什么样的人

矛盾给她一个选择，不预先规定她一定失败。下面每条有两三种落点；**已用**表示本轮或既有运行已采用现有素材，**待画**是后续方向，尚未作为新桥段上线。

| 倾向 | 可爱的矛盾 | 不同的结局方向 |
| --- | --- | --- |
| 贪睡，也舍不得错过热闹 | 想知道后面发生什么，眼皮却先撑不住 | **已用**：漫画读到有趣处笑出来；困着点头后夹好书签，今天先读到这里；**待画**：把书抱好安心睡去，不补装精神的尾巴 |
| 爱甜食，也想当大方群友 | 真想分给你，又有点舍不得 | **已用**：犹豫后主动掰一半；偷咬被看见，把更大的一半递给你；**待画**：发现只剩最后一块，想了想，轻轻放到你这边 |
| 爱耍帅，有一点薄脸皮 | 想被夸，也愿意把本事用在小事上 | **已用**：小火控制得刚刚好，坦然鞠躬；喷火过猛，吓退后认真扑灭；**待画**：原本想炫技，注意到快灭的灯，改用小火护住它 |
| 会飞，却会在高处腿软 | 自己掌控的短飞熟练，突然往下看会心虚 | **已用**：短飞后平稳收翼落地；看高处腿软，选法阵回到地面；**待画**：先抓稳边框，再被远处的东西吸引，忘了逞强，安静看一会儿 |
| 是条龙，嘴仍然怕烫 | 烧水太方便，喝水太着急 | **已用**：温度刚好，舒服地抿一口、举杯；烫到后吹凉，再小口喝；**待画**：把第二杯吹凉才递给你，让怕烫变成体贴 |
| 有一点收藏癖 | 喜欢亮晶晶，也在意谁能一起欣赏 | **已用**：擦亮宝石后递出来分享；转金币、接稳，自得其乐；**待画**：在旧收藏里发现一件忘掉的小东西，停下清点，出神地看它 |
| 好奇又好胜 | 想弄明白，也想赢，但不是每次都赢 | **已用**：游戏赢了起身举起掌机；惜败后失落地停下来，或重赛仍可能输；掌心雪花出现又消失、万花筒让她看得入迷，是小幅度的发现 |
| 喜欢创造，有一点挑剔 | 很想展示，也会被一笔画歪气到 | **已用**：画完只亮一次，得意地给你看；画歪后认真返工，再展示一次；发现脸上也沾了颜料，笑着擦掉 |
| 亲近人，有自己的小世界 | 想被注意，也能自己过日子 | **已用**：贴近「玻璃」打招呼；窝沙发安静陪着，不要求你回应；**待画**：发现你仍在忙，收回招呼，轻轻给旁边留出一个位置 |

成功不必紧接失误，失落不必马上自嘲，温柔不必先赔罪，发现也不必变成笑话。掩饰和圆场仍然是她的一种反应，但不能成为所有节目共同的句号。现有发现类素材只支持掌心和眼神的小变化；更长的出神、转移注意和身体反应需要新画，不能靠气泡替画面宣布。

龙的身体参与她的日常，也会添麻烦。尾巴很诚实：嘴上装淡定，尾尖已经翘起来。小火可以热茶、点灯；翅膀可以飞，也可以裹着睡。画面里的动作应先让观众看懂，台词只补一点性格。

## 让倾向碰到一起

一段戏选一两个有关系的倾向，不把所有萌点都挤进去。

| 碰撞 | 现有演出 | 继续挖的方向 |
| --- | --- | --- |
| 收藏 × 分享 | 擦宝石的长驻活动之后，可能递给你看 | 宝石要始终是同一颗；将来再画舍不得松手、终于放手的身体动作 |
| 困倦 × 好胜 | 精力影响游戏输赢和是否重赛；重赛不保证获胜 | 输了也可以决定今天到此为止，保留失落，不强制补偿一个胜利 |
| 贪吃 × 大方 | `sweet_sneak → sweet_share_more`，从偷偷咬到主动多分 | 不先演完道歉递出，又倒回偷咬；每条分支保留自己的因果 |
| 逞能 × 被注意 | 被摸头后偶尔露一手，可以成功，也可能失手 | 现有触发是本机互动，不推断用户是否真的在看；待画的“先确认你在看，再认真准备”不能只写进气泡 |
| 创作 × 亲近 | 本机作画后给你看，或专心返工 | 把画当礼物递出需要新素材；不能把亮画直接说成已经送到你手上 |

## 变成小龙：真的会变，但不太熟练

变龙是偶遇的惊喜。她「噗」地冒出一团云，云散开就是小龙；做一件事，再一团云变回来，用一个具体动作收尾。变身不画半人半龙的中间帧，云团在切换的那一刻已经完全盖住她。

| 小龙想做的事 | 结果 | 变回来的收尾 |
| --- | --- | --- |
| 飞给你看 | 扑腾半天只离地一点，啪地趴下转圈圈眼 | 整理一下头发，承认飞行还要练 |
| 拿糖 | 用爪子抱住了，拆不开糖纸 | 看看手心的糖：「还是手好用。」 |
| 护宝 | 圈住金币和糖，下巴一抬，慢慢打起盹 | 整理头发，满足地歇一下 |
| 追尾巴 | 追着转圈，咬到了，晕乎乎坐下 | 整理头发，缓一缓 |

只有拿糖分支接检查手心糖果的收尾；其他分支使用无糖的整理片段，避免凭空多出一颗糖。她有时会先蹦跶几步再做事。中途被戳、被拎起，或群里有事，都会马上一团云变回人形再回应。

反差来源参考「龙的能力进入琐碎日常」这类故事，形象和桥段是她自己的。

## 演出节奏

- **安静陪伴是底色**。看书、听歌、掌机这类长驻活动占大头。旧换皮动作按用途精选；保留全部素材不等于让全部素材轮番出场。
- **完整剧场有因果和落点**。起因、过程、变化、收尾可以在一张四帧里完成，也可以跨几张；烧水、倒水、吹凉、喝水只是生活流程，在完整剧场素材可用时不再占它的名额。小幅阅读、收藏结果附在原活动之后。
- **同样频率下更耐看**。自动完整剧场仍需距上次至少 180 秒、经过两次长驻，再以 45% 概率选择；不通过加快换节目展示新编排。近期已播出的结果片段会去重，减少连续演相同结尾。
- **单次和循环各有用途**。单次演出按起势稍停、中间连贯、结果稍留的节奏播一遍；持续陪伴才循环眼神、手势和尾尖的小动作。结果不会倒回起点反复发生，亮画也不接第二次相同展示。
- **稀有的事保持稀有**。小龙两次至少隔二十五分钟，启动后十分钟内不变，精力不足或开着「待在原地」时不变。家具约半小时一次。
- **被打断就放下**。群里的真实工作、拖拽和戳优先；换了活动就不再补演上一件事的结尾。家具在换节目时先收好。
- **没有单独的剧场入口**。小剧场只在日常里自然发生，「换个节目」也可能抽到。群里真实的画图、搜索、回复照真实进度演出，不使用本机虚构的输赢或创作结果。

## 画新素材的规矩

1. 先写动机、变化和情绪落点，再决定道具。给同一倾向设计两三种不同结局，先检查库里是否已有；不按乐器、甜点、宝石名词各铺一遍。
2. 每张四帧，同一镜头、同一地面线；固定头部比例和镜头，不锁死身体。允许明确的重心变化、蹲下、伸手、展翼和回身，人物与道具完整落在格内。不画地面、阴影、背景和文字。
3. 单次演出的末帧保留后果，不强求回到第一帧。循环素材只画能够自然反复的陪伴动作；入场、结果、收起另作一次性片段。
4. 串戏先核对同一件物品：硬币不能擦成宝石，纸星不能下一拍变纸鹤，不同花盆不能靠台词说成刚刚发芽。没有连续素材就缩短故事或补画。
5. 构建后对照待机帧逐帧检查头的大小。哪一帧大了或小了超过一成，就重新校准或重画；自动测量对坐姿、低头、遮脸不可靠，需要并排图人工复核。2026-11-08 有四组新素材的头大了 1.2–1.3 倍，另有几组差一成左右，都是这样查出来的。
6. 小龙动作以小龙设计稿为尺寸参照，人形动作以待机帧为参照。
7. 先在真实桌宠尺寸下完整看一遍，再隔一会儿重看。检查有没有期待、变化、停留和结束，是否需要台词解释才看懂。离线测试能证明不会卡住、重复和串错，不能证明可爱或耐看。

本轮复用并重新编排已有素材，没有把上表的待画方向算作完成。后续补图优先填情绪和因果的缺口，不以动作数量衡量进展。
