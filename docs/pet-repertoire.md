# 桌宠动作库

桌宠在本机从已经采用的动作中选节目。原有素材之外，加入 236 组四帧动作：

| 目录 | 数量 | 内容举例 |
| --- | ---: | --- |
| `regular/pet_actions_motion.py` | 64 | 不同走法、起飞与落地、上下边缘、被拎起和抛落 |
| `regular/pet_actions_dragon.py` | 72 | 龙翼和尾巴、小火苗、魔法、财宝、玩具、乐器与手作 |
| `regular/pet_actions_life.py` | 96 | 喝茶、阅读、创作、群聊忙碌，以及 12 组睡姿和 12 组额外回复动作 |
| `regular/pet_actions_boundary.py` | 4 | 藏起、跳出来、顶部倒挂探头与转正 |

每项包含动作名称、英文生图描述、姿势、场景类别、帧率、播放方式和时长等信息。`regular/pet_repertoire.py` 只选 `regular/assets/pet/sprites.json` 已收录的素材，按类型洗牌，并减少近期重复。日常以同一件道具的长驻陪伴为主，再穿插按顺序组合的茶、财宝、漫画等短剧场。一次性演出播完后进入下一步，不会循环变出道具。安静模式只挑适合静驻的活动；「换个节目」则可以主动选下一段。状态动作跟随真实状态，不需要用户逐个点播。素材清单也包含原有动作，因此总数与新增数不同。

原生桌宠按需解码 WebP 动作条，并维护有上限的近期缓存。它用本机状态安排日常、心情和作息变化；图片和动作选择本身不调用模型。小球、金币和宝石是可拖动、可归还的临时道具，最多同时两个；星光和羽毛等是几秒便淡出的鼠标透传特效，不会写进 QQ 账本。

长驻活动期间也会低频检查附近已经落地的道具，避免活动还没结束，道具就先消失。靠近、拖动或收起道具都会重新核对目标；真实工作、睡眠和本机互动优先。三个日间种子各模拟一小时，已观察到主动踢球和拾取成功。

## 高频动作怎样变化

12 组睡姿包括抱尾、枕尾、侧睡、趴睡、抱枕和覆翼；打盹有间隔，睡姿变多不会增加打盹频率。14 组回复动作分为开心、安静、斟酌和困倦等类型。心情好、精神足而且没有打开聊天面板时，她可以飞着回 QQ 消息；困了则坐着慢慢回。打开聊天面板时，她留在旁边回复。本机文字聊天也使用这套回复动作。

看图、听语音、查资料、画图和发语音各有对应动作池，持续到真实工作结束，再回到日常。正在忙的状态优先于随机节目，拖动、点击或聊天打断后仍能接着忙。

## 本轮验证

2026-11-07 首批动作库扩展有 253 次成功生图、采用 232 组；后续边缘过渡补画 6 次、采用 4 组，又重画并替换 5 组扑翼和空中回复。完整素材清单仍为 279 条。动作调度、四边隐藏与点击出场、心情与回复、睡姿、道具、素材构建及本机面板均有对应离线回归；原生 Qt 离线录制检查实际播放、裁切和点击区域。

原图缓存最多 8 组，缩放缓存最多 96 张且不超过 48 MiB；缓存会淘汰旧项。素材用人物头部测量统一比例，512×512 的透明画布为举手和展翼留出空间。同一动作条共用一次缩放；播放中不再叠加整个人物的呼吸缩放、按压缩小和落地压扁。网页会补偿透明留白，使用相同的固定比例。

素材检查要区分真正的比例漂移与蹲下、展翼、举起道具造成的外轮廓变化。整幅透明边界的高度不能当作人物身高来逐帧校正。重画的五组扑翼已逐帧核对头身比例与翅膀角度；飞行上升和悬停使用循环扑翼，起飞准备与落地各自演完再转入下一段。

拖到屏幕任一边缘松手，她会缩进去并留出可以点击的部分，直到点击或拖走再出来；鼠标靠近和群聊心跳不会让她自行离开。底边露头高度按实际素材计算，四边的不可见部分不占鼠标点击区域。

## 维护素材

`tools/pet_sprites.py` 使用原创角色定稿和已有动作表作为参考，原始动作表放在仓库外。先查看计划：

```bash
.venv/bin/python tools/pet_sprites.py generate \
  --directory ~/.the-regular --output /tmp/regular-pet-sheets \
  --stage library --group dragon --only dragon_fire_palm
```

计划只列请求和发送内容，不调用图片服务。实际生成需要在实例 `.env` 配置 `OPENAI_API_KEY`，并明确加 `--allow-paid`；需要的 `base.png` 和对应风格参考图应先放入输出目录。请求只发送原创角色参考和动作提示，不发送群聊。生成记录写入输出目录的 `requests.jsonl`；失败不会自动重试，已存在的成功图片会跳过。

候选先检查四帧的角色一致性、肢体、道具、透明度及裁切。`review` 可辅助检查布局、透明度和边缘，但不能代替人工看图：

```bash
.venv/bin/python tools/pet_sprites.py review \
  --source /tmp/regular-pet-sheets --out /tmp/regular-pet-review --group dragon
.venv/bin/python tools/pet_sprites.py build \
  --source /tmp/regular-pet-sheets --out /tmp/regular-pet-built --only dragon_fire_palm
```

`build` 离线按格子切帧、对齐并生成 WebP 与清单；检查结果及播放表现后再将选定素材纳入运行包。原始候选和请求账本不必进入仓库。动作库的日常调度由 `regular/pet_brain.py` 管理，道具计算在 `regular/pet_props.py`，原生窗口和按需加载在 `regular/desktop_pet.py`。
