# 交情与个人证据

The Regular 保留八档好感、互动次数和相处模式作为游戏机制。它们调节参与意愿和语气，不代表已经了解一个人。默认先接好眼前的话；没有个人材料时也能自然、友善、有趣。

产品目标是偶尔想起一件恰当的事、记住当事人的纠正、把眼前的话接舒服，不是先完成一个个性化实验。自然反应就是产品反馈：嫌它插话就暂时退一步，顺着玩笑往下聊就别只因脏话收场，明确的后续提问也不需要每句重新 @。判断模型可以帮助理解这些反应，代码只执行有边界的动作；不因此扣好感或给人贴永久标签。实现入口见 [判断帮手](providers.md#原生判断帮手)。

个人材料来自每日压缩已处理的本群原文。模型只提议说话人、完整原话与具体话题词；代码核对原始发言人、消息标识和时间，再决定是否收录。摘要中的性格推测不会成为个人事实。完整原话只做空白归一化，长度为 4–240 字；不截掉否定或条件来凑证据。没有名字、无法归属、指令、图片描述、敏感内容或匹配不上的条目会被跳过。新归档标记文本是否完整；被截断或无法确认完整性的旧记录不作个人原话来源，既有原始记录仍可按需查询。

接话时只取当前说话人、当前群、当前话题命中且尚未过期的原话，最多两条，只进最后的动态层。每日共享层只保留群表达参考。随机插嘴、对方喊停或已有知识库/旧账/搜索资料时，不再追加个人材料。称呼来自本地称呼记录，独立于好感和人物摘要。

时效看原始发言时间。未分类和临时近况默认两天；经过判断、并由代码核对来源的明确偏好、事实或共同经历可以保留更久，默认上限 90 天，而不是每次摘要重新续期。具体更正可以让对应的旧条目停止使用，不会清空整个人的记忆。换一种总结说法、再次压缩、重读同一消息都不会让旧材料变新。旧档案可以加载，但没有来源的个人判断不再自动注入；不回溯猜造证据。改名只更新展示，来源记录保留原样，机器标识不进入模型和群回复。

`PERSONAL_MEMORY_ENABLED=false` 关闭个人原话注入，保留称呼、游戏关系、摘要与归档。这提供普通接话的比较入口，不会偷偷多请求一次模型。

## 参考与取舍

- [MaiBot 的记忆管理](https://docs.maibot.chat/en/manual/webui/memory-management)：借鉴来源记录与人物画像的区分、错误可追查的思路。这里仍用现有 JSON/JSONL，不引入图谱或向量库。
- [SillyTavern World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)：借鉴话题命中才注入、控制上下文预算。这里不做递归激活。
- [Letta 的归档记忆](https://docs.letta.com/v1-sdk/memory/archival-memory/index.md)：参考存储与本轮可见上下文的区别。这里由本地代码选择材料，模型不获得记忆写入工具。
- Norn 的启发是先问个人信息是否比普通基线多带来帮助。本项目没有群体偏好模型，也没有搬用 Norn 的统计阈值；可核对的原话不等于个人规律已经成立。

## 已验证的边界

离线回归检查来源归属、时效、拒绝无证据条目、普通接话回退和四层提示词顺序。它们不证明真人聊天更好，也不证明模型理解了否定、转述或复杂偏好。

## 可选离线分析，不是产品准入流程

以下保留为可选分析备忘。普通接话、记忆使用和产品调整不需要先完成这些比较；不会要求群友填写评分或逐人确认，才肯根据自然反馈收敛行为。LLM 的判断可以用于有限、可恢复的产品动作，但不把它的自评分数冒充真人体验。

排查个人材料为什么没有派上用场时，`regular --directory . coverage --json`
只读统计已送达模型接话中的个人原话注入，区分直接接话、随机插话和开关状态，
并保留未知记录。没有新日志时是不可测，不是覆盖率为零。
完整分母和缺失处理见 [互动观察](interaction-observations.md#第零步先量个人原话的实际覆盖率)。

低覆盖只说明这种材料在当前规则下很少进入已送达回复，不证明普通回答已经足够，
也不证明个人材料无用。随机插话本来就不注入，不能把产品排除规则误判成话题匹配失败；
也不为提高覆盖率而放宽来源、时效或本人归属的要求。

如果机会数和自愿反馈足以支持比较，未来在原本符合准入条件的接话上，
随机选择“本人相关原话”或“不追加个人原话”，记录合格条件、分配结果和分配概率，
保持称呼、游戏关系、模型及预算等条件一致。不是对全部群消息掷骰子，
更不能把插话闸门概率当实验分配概率。本轮没有开启这种随机分配。
关闭本轮原话也不等于没有历史信息：会话可能保留先前的个性化回复，
正式协议须交代跨轮影响，不能把连续聊天的每一轮当独立样本。

当事人的反应优先，包括自然的投诉、纠正、继续接梗和追问，不局限于显式评价命令。
LLM 解释这些反应时可能出错，所以动作限于暂时退让、修正当前理解、选择有来源的材料等；
好感上涨、消息变多或无人回应都不自动代表对方满意。

**真群禁止错配材料对照。** 不将 A 的原话作为 B 的背景注入，即便只是实验也不做。
错配若有诊断价值，只能在离线、隔离且不向群友发送的环境中检查来源混淆等问题；
这种离线检查仍不能替代本人反馈或证明真实收益。

当前随机插话不使用个人原话，所以原话开关对照首先检验回复内容等方面的收益，
不是“什么时候插话”的因果实验。后者需要单独设计参与策略比较。

## 游戏称号与了解证据

交情和“接得准”是两条线。现有好感与互动仍是游戏状态；若未来加入表示
“认出你的规律”的成就，不能用好感、互动数、原话条数或一次关键词命中自动解锁。
本人确认某次接得对，也不等于系统从此什么都懂。

“老熟人”可以表达真实共同经历、记住纠正和几次接得上的默契，不必先通过个人模型
优于群体模型的统计检验；它是游戏关系，不是读心认证。也不把奖励绑到给好评上。
本轮不新增称号、不设置解锁阈值，也不修改已有好感和档位。
