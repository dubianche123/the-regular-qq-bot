# The Regular 0.6.0 · 小团团有了自己的小日子

这次桌宠大更新：她会自己过日子、会变小龙，也会把龙的本事用在小事上。

- **日常有始有终**：看漫画笑出声或夹好书签，打掌机有输有赢、输了还想再来一局，画歪了擦掉重画，弹完琴、用完电脑会收好。她会主动分点心、把最后一块饼干留给你；被摸头后偶尔露一手，喝茶太心急也会烫到舌头。椅子、沙发偶尔搬出来窝一会儿。安静陪伴仍是底色，小剧场在日常里自然出现。
- **噗地变成圆滚滚的小龙**：还是她的脸、头发、角和围巾，一团云遮住变身。试飞摔趴、拆不开糖、圈着宝物打盹或者追尾巴转晕，再变回来。自然变龙是偶遇的惊喜；她醒着、空闲且开启动作时，首次成功点「更多 → 变个魔法」就优先展示小龙，之后轮换小龙、日常小魔法和有目标的传送。
- **龙的本事用在小事上**：冰息冰可乐、小火苗烤棉花糖、暖气吹干围巾、让小刷子飞过去梳尾巴、金线修书角。主动开阵会去找远处真实存在的球或宝物；群里有人 @ 她、你的光标又离得远时，她还会传送到光标下面看消息。偶尔一个喷嚏也会把自己打进魔法阵，落地后才发现不对劲。
- **飞得更像在飞**：斜着起飞，一路拍翅膀，转向时身体会倾斜，落地前先伸脚。在空中偶尔喷一口小火，或者追你晃动的鼠标。
- **四边藏身也有小动作**：贴着屏幕边松手，她把身子藏在屏幕外，探头、侧耳听、打哈欠、打盹。顶边倒挂时只露脑袋和必要手部，离开前先在原位开好魔法阵。把她拎到高处再松手，她落地后偶尔会腿软坐下、抱着翅膀壮胆——会飞，但怕高。
- **投喂连贯，点击更准确**：接饼干、咬一口、吃完回应沿用同一套人物比例，延迟回执不会再吃一遍。透明处的点击直接穿过去，鼠标越过人物轮廓不再让窗口闪烁；追光标时也不会拦住你的点击。「换个节目」会先收好手里的电脑或乐器，新节目按正常节奏播放。
- **Agent 叫你**：接上 [Codex / Claude Code Hooks](../agent-notifications.md)（`regular pet-notify`），一轮回复结束时她会叫你；Claude Code 请求权限时也能提醒。

新用户可以在 GitHub Release 下载 **Source code (zip)** 并完整解压，或者把 [README 里的安装 prompt](../../README.md#开始使用) 交给编码 Agent。wheel 与 tar.gz 供已有 Python 环境使用。动作素材现有 377 条 WebP 动作条、1,502 帧，总计约 38 MB，安装包也随之增大：本轮候选 wheel 约 42.6 MB，源码 tar.gz 约 47.2 MB，精确大小以最终发布附件为准。
